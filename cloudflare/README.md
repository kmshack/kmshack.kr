# Edge content negotiation for kmshack.kr

`kmshack.kr` is a static Jekyll site on GitHub Pages, proxied through Cloudflare.
GitHub Pages serves files; it cannot pick a representation based on the request's
`Accept` header, set `Vary`, or return a JSON error body. This Worker adds those
three things at the edge.

**The site works without it.** Everything else — the pages, the Markdown twins,
the JSON API, `llms.txt`, `openapi.json` — is plain static output. Deploying this
Worker is what makes the following true:

| Behaviour | Without the Worker | With the Worker |
| --- | --- | --- |
| `Accept: text/markdown` on `/` | `text/html` | `text/markdown; charset=utf-8`, same URL |
| `Vary` on page responses | `Accept-Encoding` | `Accept, Accept-Encoding` |
| Unsatisfiable `Accept` | `200` HTML | `406 Not Acceptable` |
| `GET /api/does-not-exist.json` | the site's HTML 404 page | `404` + `Error` JSON body |
| Markdown twin advertised | `<link rel="alternate">` in the HTML | also a `Link:` response header |

Markdown twins are generated by Jekyll (`about-md.html` → `/about.md`, and so on),
so the Worker never converts anything — it only chooses which file to return.

## Deploy

Requires an account with the `kmshack.kr` zone, and the domain proxied through
Cloudflare (it already is).

```bash
cd cloudflare
npx wrangler login
npx wrangler deploy
```

`wrangler.toml` binds the Worker to the route `kmshack.kr/*`. It makes one
subrequest per markdown negotiation and none otherwise, so the free plan's
request budget is ample.

## Verify after deploying

```bash
# 1. Markdown from the canonical URL
curl -sI -H "Accept: text/markdown" https://kmshack.kr/ | grep -i '^content-type\|^vary\|^link'

# 2. Browsers still get HTML
curl -sI -H "Accept: text/html,*/*;q=0.8" https://kmshack.kr/ | grep -i '^content-type\|^vary'

# 3. q-values are honoured (HTML preferred → HTML)
curl -s -o /dev/null -w '%{content_type}\n' \
  -H "Accept: text/markdown;q=0.5, text/html;q=0.9" https://kmshack.kr/

# 4. Unsatisfiable Accept → 406
curl -s -o /dev/null -w '%{http_code}\n' -H "Accept: application/pdf" https://kmshack.kr/

# 5. JSON errors on the API surface
curl -s https://kmshack.kr/api/does-not-exist.json

# 6. Real 404s stay real
curl -s -o /dev/null -w '%{http_code}\n' https://kmshack.kr/some-path-that-does-not-exist
```

The same expectations are asserted by `tests/verify_agent_readiness.py --base https://kmshack.kr`.

## Unit tests

The negotiation logic runs on stubbed `fetch()` in `tests/worker.test.mjs`:

```bash
node --test tests/worker.test.mjs
```

## If you would rather not run a Worker

A Cloudflare **Transform Rule → Modify Response Header** can add
`Vary: Accept, Accept-Encoding` to responses whose URI path does not start with
`/assets/`. That fixes the cache-correctness half of the problem, but not
Markdown negotiation, `406`, or JSON errors — those need code at the edge.
